A two-part micro-confession for the [make.fun bounty](https://make.fun/c/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba): a `To:` line naming who the unsent message was meant for, and the unsent message itself — one line, exactly as it was typed, with nothing after it.

`main.py` writes the confession to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The text is fixed and deterministic: the same confession on every run.

## The confession

```text
To: the girl from table six
I wrote your number on my hand and washed it off before I could decide if I was brave or just lonely.
```

## Run it

```sh
python3 main.py
```
